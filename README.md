## Датасеты
https://www.kaggle.com/datasets/simongraves/synthetic-printed-canadian-passports
https://www.kaggle.com/datasets/simongraves/synthetic-printed-japanese-passports

## Скрипты
- train.py - тренировка модели
- predict.py - тестовое предсказание модели
- script.py - итоговый скрипт с pytesseract. В нем image_path содержит ссылку на картинку для обработки

## Доп. файлы
- test_images - папка для тестового прогона predict.py и script.py. В ней лежат картинки из тренировочного и валидационного датасета
